📨 HTTP-запрос · CRUD · Методы · Коды ответа 🚦

🧱 Структура HTTP-запросаПример 
GET /api/users HTTP/1.1    ← Start Line (Метод + URI + Версия)
Host: vk.ru                       ← Заголовки (Headers)
Authorization: Bearer token123     ← Заголовки
Content-Type: application/json     ← Заголовки
                                    ← Пустая строка (Empty Line) — разделитель
{ "name": "John" }                ← Тело (Body) — опционально
🚀 Start Line / Request Line
Метод, URI, версия HTTP
📋 Headers
Метаданные — тип контента, авторизация, куки
⬜ Empty Line
Разделяет заголовки и тело
📦 Body
Данные запроса — POST / PUT / PATCH
➕ Create (Создать)
POST · INSERT
🔍 Read (Прочитать)
GET · SELECT
🔄 Update (Обновить)
PUT PATCH · UPDATE
🗑️ Delete (Удалить)
DELETE · DELETE
🔍 GET
Запрос данных (без тела)
📄 HEAD
Только заголовки (без тела)
🔧 OPTIONS
Спрашивает, какие методы поддерживает сервер
➕ POST
Создаёт ресурс — не идемпотентный
🔄 PUT
Полная замена ресурса — идемпотентный
✏️ PATCH
Частичное изменение — не всегда идемпотентный
🗑️ DELETE
Удаляет ресурс — идемпотентный
🔄 Идемпотентный
Метод, который можно вызвать несколько раз с одинаковым результатом
Пример: PUT /users/1 — первый раз создаст, второй раз просто перезапишет (состояние то же)
🛡️ Безопасный
Метод не изменяет ресурс на сервере (только читает)
GET, HEAD, OPTIONS — безопасные

ℹ️ 1xx — Информационные
102 ProcessingСервер принял запрос, но ещё не завершил обработку (WebDAV)
✅ 2xx — Успех
200 OKЗапрос успешно выполнен
201 CreatedРесурс создан (обычно POST)
↪️ 3xx — Перенаправление
301 Moved PermanentlyРесурс навсегда перемещён на новый URL
302 FoundВременное перенаправление
⚠️ 4xx — Ошибка клиента
400 Bad RequestСервер не понимает запрос (невалидные данные)
401 UnauthorizedТребуется аутентификация
403 ForbiddenДоступ запрещён (аутентификация есть, но прав нет)
404 Not FoundРесурс не найден
405 Method Not AllowedМетод не поддерживается для этого ресурса
💥 5xx — Ошибка сервера
500 Internal Server ErrorОбщая ошибка сервера
501 Not ImplementedСервер не поддерживает нужную функциональность
503 Service UnavailableСервер временно перегружен или на обслуживании
505 HTTP Version Not SupportedСервер не поддерживает версию HTTP
