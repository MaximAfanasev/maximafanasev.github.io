🔧 Git · DevOps · CI/CD · ООП 🧱

📂 РепозиторийGit
Папка с проектом — локальная .git или удалённая на GitHub / GitLab
📍 КоммитGit
Точка (слепок) изменений с хешем и сообщением
🌿 Ветка (Branch)Git
Последовательность коммитов — изолированная линия разработки
💻 Базовые команды Git (ключевые)
git init git clone git add git commit git push git pull git branch git merge
🐳 DockerDevOps
Контейнеризация — упаковка приложения со всеми зависимостями
☸️ Kubernetes (k8s)DevOps
Оркестрация контейнеров — автоматическое развёртывание и масштабирование
⚙️ JenkinsDevOps
CI/CD сервер — автоматизирует сборку, тесты и деплой
🔄 CIContinuous Integration
Непрерывная интеграция — каждый коммит автоматически собирается и тестируется
🚀 CDContinuous Delivery / Deployment
Непрерывная поставка / развёртывание — автоматическая выкатка на окружения вплоть до Prod
🌐 Окружения (Environments)
Среда (Environment) — это инфраструктура: физические серверы, виртуалки, сетевые устройства, облака
🛠️ Dev Создание — разработчики пишут код
👀 Demo Можно потрогать — показать заказчику
🧪 Test Тестирование — авто- и ручное
🏁 Stage Предпрод — максимально похож на бой
🌍 Prod Production — видят все пользователи
📐 КлассыООП
Шаблоны для создания объектов — чертёж
📦 ОбъектыООП
Структуры с данными (атрибутами) и методами (поведением)
🏷️ АтрибутыООП
Характеристики (поля) объекта — цвет, размер, имя
⚡ МетодыООП
Поведение объекта — функции, которые он может выполнять
🔒 Инкапсуляция
Информация хранится внутри объекта — скрываем детали
🎭 Абстракция
Выделяем общие атрибуты и методы, убирая лишнее
🧬 Наследование
Создание новых классов на основе существующих — родитель → потомок
🔄 Полиморфизм
Один и тот же метод работает по-разному для разных классов
