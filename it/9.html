9. ПРОТОКОЛ

HTTP

HyperText Transfer Protocol протокол передачи гипертекста

URI / URL

Uniform Resource Identifier Uniform Resource Locator URI = URL — протокол + доменное имя
http:// протокол vk.ru доменное имя http://vk.ru URI / URL

СТРУКТУРА ЗАПРОСА

📄 Start Line / Request Line — метод + URI + версия HTTP 📋 Заголовки HEADERS — метаданные запроса ⬜ Пустая строка EMPTY LINE — разделитель 📦 Body — тело запроса (опционально)

CRUD

Create Read Update Delete
C → Post R → Get U → Put / Patch D → Delete

МЕТОДЫ HTTP

GET — запрос ресурса HEAD — только заголовки OPTIONS — поддерживаемые методы POST — создаёт ресурс PUT — заменяет ресурс целиком PATCH — частичное изменение DELETE — удаляет ресурс

СВОЙСТВА МЕТОДОВ

Идемпотентный
несколько раз → тот же результат
🔄 GET, PUT, DELETE, HEAD, OPTIONS
Безопасный
не изменяет ресурс на сервере
🛡️ GET, HEAD, OPTIONS
