1. Система контроля версий (Git)

📂 Репозиторий
Папка с проектом (локальная .git или удалённая на GitHub/GitLab).
📍 Коммит
Точка (слепок) изменений с хешем и сообщением.
🌿 Ветка (Branch)
Последовательность коммитов (изолированная линия разработки).

Базовые команды Git (ключевые)

Команда Что делает
git commit -m "fix" Создает коммит (точку сохранения)
git log --oneline Показывает историю коммитов (сокращённо)
git push origin main Отправляет коммиты в удалённый репозиторий
git merge feature Сливает ветку feature в текущую
git pull Скачивает изменения с удалённого репо и сливает (fetch + merge)
git checkout -b new Создаёт и переключает на новую ветку (с - switch/create)
git branch -vv Показывает все ветки и их привязку к удалённым (вв — очень подробно)

2. DevOps (Development & Operations)

🐳 Docker
Контейнеризация — упаковка приложения со всеми зависимостями.
☸️ Kubernetes (k8s)
Оркестрация контейнеров (автоматическое развертывание, масштабирование).
⚙️ Jenkins
CI/CD сервер — автоматизирует сборку, тесты и деплой.

3. CI/CD (Непрерывная интеграция и доставка)

🔄 CI (Continuous Integration)
Непрерывная интеграция — каждый коммит автоматически собирается и тестируется.
🚀 CD (Continuous Delivery / Deployment)
Непрерывная поставка / развертывание — автоматическая выкатка на окружения (вплоть до Prod).

4. Окружения (Environments)

Среда (Environment) — это инфраструктура: физические серверы, виртуалки, сетевые устройства, облака.
🛠️ Dev — Создание (разработчики пишут код)
👀 Demo — Можно потрогать (показать заказчику)
🧪 Test — Тестирование (авто- и ручное)
🏁 Stage — Предпрод (максимально похож на бой)
🌍 Prod — Production (видят все пользователи)

5. Объектно-Ориентированное Программирование (ООП)

📐 Классы — Шаблоны для создания объектов (чертёж)
📦 Объекты — Структуры с данными (атрибутами) и методами (поведением)
🏷️ Атрибуты — Характеристики (поля) объекта (цвет, размер, имя)
⚡ Методы — Поведение объекта (функции, которые он может выполнять)

Принципы ООП (4 столпа)

🔒 Инкапсуляция — информация хранится внутри объекта (скрываем детали).
🎭 Абстракция — выделяем общие атрибуты и методы, убирая лишнее.
🧬 Наследование — создание новых классов на основе существующих (родитель → потомок).
🔄 Полиморфизм — один и тот же метод работает по-разному для разных классов.

6. UX/UI Дизайн

😊 UX (User Experience) — Опыт пользователя от взаимодействия с системой (удобство, эмоции).
🎨 UI (User Interface) — Как выглядит продукт (кнопки, цвета, шрифты).

Юзабилити (Usability) — оцениваем по:

  • Удобство — легко ли пользователю достигать целей.
  • Интуитивность — понятно ли с первого взгляда.
  • Нет ошибок — система предотвращает или прощает ошибки.
  • Удовлетворение — приятно ли пользоваться.

Инструменты и подходы (Figma и не только)

📱 Адаптивность — подстраивается под экран (мобилка/планшет/ПК).
⚡ Отзывчивость — моментальная реакция на действия пользователя.
🎮 Геймификация — игровые механики (бонусы, уровни).
🏢 Внутренняя — для сотрудников компании (ERP, CRM).
🌐 Внешняя — для клиентов и пользователей (сайты, приложения).

7. Web: Домены, DNS, IP, URL

🌐 Домен — Человекочитаемое имя сайта (example.com).
📖 DNS (Domain Name System) — Переводит домен в IP-адрес (как телефонная книга).
🔢 IP-адрес — Уникальный сетевой адрес устройства (192.168.1.1).
🔗 URL (Uniform Resource Locator) — Полный адрес ресурса: https://domain.com/path?param=1.
