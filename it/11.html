ТИПЫ ЗАПРОСОВ

DDL — Data Definition Language

определение данных
CREATE — CREATE TABLE, CREATE USER ALTER — модифицировать DROP — удалить

DML — Data Manipulation Language

изменение данных
SELECT — выборка INSERT — вставка UPDATE — обновление DELETE — удаление MERGE — слияние

DCL — Data Control Language

управление данными
GRANT — разрешение на операции REVOKE — отзыв DENY — запрет

TCL — Transaction Control Language

BEGIN / COMMIT — объявление транзакции ROLLBACK — откатывает изменения
