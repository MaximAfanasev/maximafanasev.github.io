8. API

ЧТО ТАКОЕ API?

Application Programming Interface правила и способы обмена данных 🍕 официант — передаёт заказ между клиентом и сервером

ENDPOINT

конечная точка URL — адресат запроса https://api.site.com/users https://api.site.com/products/123

ТИПЫ API

Открытые (Public)
для связи между серверами
🌍 без токена, общедоступные
Партнёрские
для внешних партнёров
🤝 доступ по ключу/токену
Внутренние
для использования внутри компании
🏢 только для внутренних сервисов
Составные (Composite)
объединяет несколько API
🔗 агрегация данных из разных источников

REST API

Representational State Transfer Передача самоописываемого состояния
🏗️ Клиент-серверная архитектура 🚫 Отсутствие состояния (stateless) 💾 Кэшируемость 📐 Единообразие (uniform interface) 🧅 Слои (layered system) 📜 Код по требованию (code on demand — опционально)

SOAP API

Simple Object Access Protocol протокол обмена структурированными сообщениями XML WS-Security WS-Addressing

GRAPHQL

язык запросов клиент запрашивает только нужные данные
📊 Один эндпоинт 🎯 Только нужные поля 🔄 Вложенные запросы 📝 Сильная типизация

ФОРМАТЫ ДАННЫХ

XML
EXtensible Markup Language
📄 <user><name>John</name></user>
JSON
JavaScript Object Notation
📦 {"user": {"name": "John"}}
